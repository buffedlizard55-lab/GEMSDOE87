The exact submission process—for a future cleared file only

Do not perform the following upload steps with this negative artifact. A real submission requires a future independent selector authorization after all gates pass.

  1. Check the file-specific decision. Confirm the exact hash, format validator, individual feature canaries, spatial holdout improvement, and complete scoped registry clearance. A format PASS alone is not sufficient.
  2. Obtain separate selector authorization. The selector must read the actual current cap and remaining usage on the authenticated submission page. This run did not select an entry. The rules PDF's weekly limit is not an account-specific receipt.
  3. Download the cleared .tif or its one-TIFF .zip. On DrivenData choose New submission → File to submit, then select that TIFF or ZIP—not this website, JSON, or executive summary.
  4. Use the exact identification and short note. Keep it within the project limit, and retain the file SHA-256 with the submission-page receipt. Do not represent a projected or holdout value as an organizer score.
  5. Record the organizer response. Only a real receipt can establish upload acceptance and the score of that exact artifact. Eligibility and any required generative-AI narrative disclosure still apply.
