How to read these numbers

HOLDOUT-DTI is a local hide-and-recover score on catalogue positives, not an organizer score and not a leaderboard projection. Each entry names the control it was paired against; an interval that includes zero is a failure to demonstrate improvement, regardless of which point estimate is larger. Negative results are retained rather than deleted because they define which mechanisms have already been ruled out.
